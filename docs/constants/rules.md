# constants/ — Правила

## Что это
Глобальные константы-примитивы без side-effects.

## Структура
```
constants/
  ├── regex.ts
  └── routes.ts
```

## Правила
- Только **примитивы и конфигурационные объекты**.
- **Листовой узел**: не импортирует ни из каких слоёв.
- Не содержит API-константы (notification messages) → они в `services/`.

## Нельзя
- Импортировать из `services/`, `store/`, `components/`, `lib/`.
- Класть функции с side-effects.
