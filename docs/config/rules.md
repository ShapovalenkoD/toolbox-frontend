# config/ — Правила

## Что это
Типизированный доступ к env-переменным и feature flags.

## Структура
```
config/
  ├── env.ts                 # Типизированные env-переменные
  └── features.ts            # Feature flags (булевы флаги с дефолтами)
```

## Правила
- Весь проект импортирует env через `config/env.ts`, **не напрямую** из `process.env`.
- `env.ts` **валидирует** переменные при запуске — отсутствующие = ошибка.
- Feature flags — типизированы, с дефолтами.

## Нельзя
- Читать `process.env` напрямую.
- Оставлять feature flags без дефолтного значения.
