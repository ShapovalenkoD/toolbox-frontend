# assets/ — Правила

## Что это
Статические ресурсы: изображения, шрифты, SVG-иконки.

## Структура
```
assets/
  ├── images/
  ├── fonts/
  └── icons/                 # SVG как файлы (background, img src)
```

## Правила
- Именование: **kebab-case**.
- SVG как компоненты → `components/ui/atoms/icons/`.
- SVG как файлы → `assets/icons/`.
