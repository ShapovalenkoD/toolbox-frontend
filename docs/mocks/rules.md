# mocks/ — Правила

## Что это
Моковые данные для тестов и разработки.

## Структура
```
mocks/
  ├── service/               # Моки API-сервисов
  └── components/            # Моки для пропсов компонентов
```

## Правила
- Импортируются **только** из тестов и stories.
- **Листовой узел**: не импортирует ни из каких слоёв.

## Нельзя
- Импортировать моки в рабочий код.
- Использовать моки в stories (stories должны быть самодостаточными).
