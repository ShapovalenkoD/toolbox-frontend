# lib/ — Правила

## Что это
Переиспользуемые утилиты и хуки. Чистые функции без side-effects.

## Структура
```
lib/
  ├── hooks/                 # Переиспользуемые хуки (2+ мест)
  ├── utils/                 # Чистые утилиты (formatPrice, declOfNum)
  ├── business/
  │   └── formatters/        # Маски, Zod-схемы для форм (дата, деньги, числа)
  └── ts/                    # TS-хелперы (дженерики)
```

## Правила
- **Не импортирует** из `services/`, `store/`, `components/`.
- Только внешние библиотеки.
- Хук для 1 места → рядом с компонентом (`*.hooks.ts`), не сюда.
- `business/formatters/` — Zod-схемы для полей форм, маски ввода. Это **не** валидация API-ответов.

## Нельзя
- Импортировать `services/`, `store/`, `components/`.
- Класть side-effects в `lib/`.
- Класть бизнес-логику в `utils/`.
