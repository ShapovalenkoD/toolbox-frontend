# План: Связать AI_RULES.md с per-folder rules.md

## Контекст

У нас два уровня документации:
1. `docs/AI_RULES.md` — общие правила (81 строка, копируется в новые проекты)
2. `docs/<слой>/rules.md` — детальные правила конкретного слоя (20-30 строк каждый)

Проблема: они не связаны. ИИ-агент прочитает общие правила и не узнает о деталях в per-folder файлах.

## Что сделать

В `docs/AI_RULES.md` в каждый раздел "По слоям" добавить строку-ссылку:

```markdown
### `components/business/`
- ...существующие правила...
- Подробнее: `docs/components/business/rules.md`
```

Также добавить в конец файла общую секцию:

```markdown
## Детальные правила по слоям

| Слой | Путь |
|---|---|
| app | `docs/app/rules.md` |
| components/ui | `docs/components/ui/rules.md` |
| components/business | `docs/components/business/rules.md` |
| services | `docs/services/rules.md` |
| store | `docs/store/rules.md` |
| lib | `docs/lib/rules.md` |
| config | `docs/config/rules.md` |
| constants | `docs/constants/rules.md` |
| mocks | `docs/mocks/rules.md` |
| assets | `docs/assets/rules.md` |
```

## Файл для изменения

- `docs/AI_RULES.md` — добавить ссылки в каждый подраздел + таблицу в конце

## Verification

- Прочитать `AI_RULES.md` → убедиться что каждый слой имеет ссылку на свой `rules.md`
- Проверить что все 10 ссылок ведут на существующие файлы
